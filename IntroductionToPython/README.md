# Introduction to Python

Programming foundations for computational social science.

## Techniques

- Scalar and non-scalar types (`str`, `list`, `tuple`, `set`, `dict`)
- Control flow: branching, `for` / `while`, comprehensions
- Functions, scope, and modules
- Object-oriented basics (classes)
- Applied mini-project: compare inaugural speeches (tokenize, frequency, vocabulary)

## Key files

| File | Role |

| `python_intro.ipynb` | Core workshop notebook |
| `python_example.ipynb` | Trump vs. Biden speech comparison walkthrough |
