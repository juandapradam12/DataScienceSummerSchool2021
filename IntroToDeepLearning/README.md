# Introduction to Deep Learning

Neural networks for classification and regression, with careful train / validation / test practice.

## Techniques

- Multilayer perceptrons on MNIST digits
- Proper train–validation–test splits and hyperparameter exploration
- Feature normalization for tabular regression (Boston housing)
- Loss curves, overfitting awareness, and evaluation metrics
