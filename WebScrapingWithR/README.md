# Web Scraping with R

Collect structured data from the web: APIs, HTML scraping, and browser automation.

## Techniques

- Legal / ethical basics of web data collection
- RESTful APIs: plug-and-play clients (e.g. Twitter) and custom queries (e.g. NYT)
- HTML / CSS structure, SelectorGadget, and programmatic multi-page scrapes
- Selenium for pages that need a real browser
