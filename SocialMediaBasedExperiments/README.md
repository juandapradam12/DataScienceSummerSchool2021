# Social Media–Based Experiments

Design, randomization, and analysis for experiments that run in online / social-media settings.

## Techniques

- Random assignment with `randomizr`
- Randomization inference (`ri2`)
- Design-based estimation (`estimatr`)
- Individual-level analysis and clustering perspectives
- Reproducible lab write-ups (R Markdown)
