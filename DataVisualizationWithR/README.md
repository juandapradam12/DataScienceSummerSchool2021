# Data Visualization with R

Build clear exploratory and presentation graphics for social-science data.

## Techniques

- Univariate summaries and base-R high-level plots
- Comparative charts (Gapminder life expectancy / GDP style views)
- Bullet graphs for performance vs. target
- Tableplots for high-dimensional categorical exploration
- Joy-plot / ridgeline-style population maps

## Key files

| Path | Role |
|---|---|
| `code/basic_graphs.R` | Core plotting lab (Gapminder) |
| `code/advanced_lab.R` | Bullet graphs, tableplots, map layers |
| `code/data/` | Gapminder, Swiss census, Germany population points |
| `lecture.pdf` / `lab.pdf` | Lecture & lab slides |

## Tools

R · base graphics · `foreign` · mapping helpers (`maps`, etc.)

## How to run

From `code/`:

```r
source("basic_graphs.R")
# source("advanced_lab.R")
```
