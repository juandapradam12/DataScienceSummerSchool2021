# Images as Data

Treat images as numeric tensors and train convolutional models for recognition tasks.

## Techniques

- Pixel scaling / normalization to \[0, 1\]
- One-hot labels for multi-class digit recognition
- Convolutional neural network (CNN) architecture in Keras
- Train / evaluate loops; transfer-style retraining workflow on MNIST-like data

## Key files

| File | Role |
|---|---|
| `RetrainingACNN.ipynb` | Build, train, and evaluate a CNN |

## Tools

Python · Keras · Jupyter

## Takeaway

Bridges “images as matrices” to a working deep-learning classification pipeline — the same pattern used in applied image measurement.
